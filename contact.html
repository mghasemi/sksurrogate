sksurrogate/ contact

One address, three destinations.

SKSurrogate is maintained software, not a hosted service — there is no sales team and no support desk. Route the message to the right place and it gets read.

Email: mehdi.ghasemi@gmail.com

Bug reports

Use the GitHub issue tracker. A report that can be reproduced gets fixed; one that cannot gets a question. Please include:

  • the version — python -c "import sksurrogate; print(sksurrogate.__version__)"
  • your Python and scikit-learn versions
  • a minimal snippet or dataset shape that triggers the problem, and the full traceback
  • what you expected versus what happened

Search the existing issues first; duplicates are closed with a pointer rather than an answer.

Usage questions

The documentation answers most installation, API and control-plane questions, and the benchmark post explains what the package does and does not claim. If something is genuinely unclear after that, open an issue with the question label or send email — documentation gaps are treated as bugs.

Corrections to published results

Numbers on this site come from the benchmark suite in the repository. If you find an arithmetic error, a mismatched table, or a claim the archived records do not support, email or open an issue with the dataset, budget and seed cell you are checking. Material corrections are recorded in the changelog rather than applied silently.

Security

Do not open a public issue for a security problem. Email mehdi.ghasemi@gmail.com with a subject line beginning [security], including the affected version, the impact, and a reproduction if one exists. You will get an acknowledgement; fixes for confirmed issues are released as a patch version and noted in the changelog once users can update.

What this project does not offer

No support contracts, no service-level agreements, no paid consulting, and no hosted demo to book. The software is MIT-licensed and self-service by design: everything it does is installable in one command and exercised by the published benchmarks.

This website

The site is static HTML with no cookies, no analytics and no third-party trackers. Fonts are loaded from Google Fonts and the pages are served by GitHub Pages, which may log requests under GitHub's privacy statement. Nothing else is collected.
