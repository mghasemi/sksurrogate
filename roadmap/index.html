sksurrogate/roadmap

Roadmap

Dated and gated. An item says “next” or “later” — never “it does that today” unless it shipped.

Shipped since this page was written

v0.8.0 (November 2026): an MCP server that exposes the control plane to agents, paired model comparison on one shared fold list with bootstrap intervals and Holm-adjusted tests, and evidence-labelled LLM drafting in which every sentence carries its label and citation and causal wording is refused at validation.

Next

Quantile / conformal-interval diagnostics in the UI and API — the Python split-conformal protocol already ships; the calibration-data contract for serving them is the next step. Alongside it: benchmark v2.0, a cost-axis comparison matrix, published only once its design is final and the full suite is re-run to protocol.

Later

A conversational research assistant beyond single-shot evidence-labelled drafts — still bound by the same citation-forcing contract: every sentence labelled and cited, causal claims refused at validation. Shipped only with its gates intact.

Not on the roadmap

A managed cloud service, a fixed model zoo, or a chat assistant inside the box. See what SKSurrogate is not.
