sksurrogate/roadmap

Roadmap

Dated and gated. An item says “next” or “later” — never “it does that today” unless it shipped.

Next

Quantile / conformal-interval diagnostics in the UI and API — the Python split-conformal protocol already ships; the calibration-data contract for serving them is the next step.

Later

LLM-assisted synthesis beyond bounded cited notes — toward a human-gated, citation-enforced research assistant. Shipped only with its gates intact.

Not on the roadmap

A managed cloud service, a fixed model zoo, or a chat assistant inside the box. See what SKSurrogate is not.
