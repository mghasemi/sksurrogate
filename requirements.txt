# Umbrella dev/CI manifest. This is *not* what `pip install sksurrogate` installs:
# the wheel's install_requires is requirements-core.txt only, and every optional
# backend is an extra (`pip install "sksurrogate[estimators]"`,
# `"sksurrogate[ui]"`, `"sksurrogate[all]"`, ...).
#
# Tiered manifests, lowest to highest weight:
#
#   requirements-core.txt     numpy, scipy, pandas, scikit-learn, joblib, peewee, tqdm
#   requirements-extras.txt   gradient-boosting backends, SALib, eli5, skrebate,
#                             imbalanced-learn, matplotlib, category-encoders
#   requirements-api.txt      FastAPI/uvicorn stack + dask (control plane, web UI)
#   requirements-dev.txt      all of the above + pytest/pygments/httpx (CI, Docker)
#
# Lower bounds exclude all historically vulnerable ranges per the GitHub Advisory
# Database (Dependabot triage, 2026-10-24); no upper pins -- CI intentionally
# tracks current releases.
-r requirements-core.txt
-r requirements-extras.txt
-r requirements-api.txt
pytest
pygments
httpx
