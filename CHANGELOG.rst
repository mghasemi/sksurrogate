Changelog
=========

The changelog lives in ``docs/changelog/`` — one page per release — and is
part of the published documentation:

    docs/changelog/index.rst        index of all releases
    docs/changelog/0.4.0.rst        latest release

This root file exists because tools and release scripts expect a
``CHANGELOG.rst``; it deliberately holds no entries. Add new notes to
``docs/changelog/<version>.rst`` and list the page in
``docs/changelog/index.rst``.
